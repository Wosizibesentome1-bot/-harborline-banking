# Harborline Digital Banking Demo

A responsive, front-end-only banking interface prototype.

## Safety and scope
- Harborline is fictional and is **not a bank or financial institution**.
- All balances, account references, card details and transactions are illustrative.
- No real money movement, deposits, withdrawals, payments, card processing, identity verification or bank connections are supported.
- The profile form is for fictional display details only. It does not transmit or persist data to a server.
- Do not enter real passwords, OTPs, card numbers, account numbers or identity documents.

## Run locally
Open `index.html` in a modern browser, or deploy this repository as a static site.
